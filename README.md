# SAIFI Data Analysis Dashboard

## Overview
This project provides an interactive dashboard to analyze the Annual SAIFI (System Average Interruption Frequency Index) Data for the years 2013 to 2025. The dashboard enables users to visualize and explore trends in power supply reliability, aiding data-driven decision-making for energy researchers, providers, policymakers, and community stakeholders.

## Features
- Interactive visualizations for SAIFI trends.
- Benchmarking tools for comparative analysis.
- Customizable reports.
- Real-time data updates.
- Mobile-friendly design.
- Multi-language support (English and Arabic).

## Installation
To run the project locally, follow these steps:

1. Clone the repository:
   bash
   git clone https://github.com/yourgithubaccount/saifi-dashboard.git
   cd saifi-dashboard
   

2. Install the required Python packages:
   bash
   pip install -r requirements.txt
   

3. Run the Python script:
   bash
   python saifi_dashboard.py
   

## Usage
1. Place the `SAIFI.csv` file in the root directory of the project.
2. Run the script using the command mentioned above.
3. Use the generated dashboard to visualize and analyze SAIFI trends.
4. Use the filtering options to explore specific years or regional data.
5. Export customized reports as required.
